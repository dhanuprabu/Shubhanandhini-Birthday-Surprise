---
name: Recipient editing boundary
description: Intentional content-editing behavior for the birthday surprise site.
---

The recipient-facing birthday surprise is a finished, read-only gift. Do not reintroduce public controls for changing the name, messages, memories, captions, or photos. Personal audio selection remains a separate playback feature.

**Why:** The user asked to remove the edit option for the surprise recipient so the page stays a prepared reveal.

**How to apply:** If creator-side personalization returns, keep it in a separate authoring view or behind an access boundary rather than in the shared recipient experience.
